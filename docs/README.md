# Dímelo

App pessoal de estudo de espanhol para quem fala português do Brasil, do A1 ao C2. Funciona sem internet depois da primeira visita.

- O conteúdo do A1 está pronto, em rascunho: 107 unidades e 478 atividades.
- Os demais níveis já aparecem no mapa, mas ainda sem conteúdo.
- A revisão espaçada usa o FSRS (biblioteca ts-fsrs).
- O progresso fica guardado só no aparelho (IndexedDB). Para não perder nada, use **Eu → Salvar cópia** de vez em quando.

Esta pasta é gerada por `scripts/gerar_app.py` a partir de `dados/`. Não edite `data/conteudo.json` à mão.
