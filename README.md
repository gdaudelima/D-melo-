# Dímelo

App pessoal de espanhol para quem fala português (PWA offline). Publicado pelo GitHub Pages a partir da raiz do branch `main`.

- Raiz: o app (index.html, css/, js/, data/, img/, fonts/, icons/, sw.js).
- `desenvolvimento/`: scripts de geração, dados do currículo, testes Playwright, PRODUCT.md e DESIGN.md (não usados pelo app).
